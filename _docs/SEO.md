# Search: how vochuseasysave.com gets found

## On the site (done)

- `robots.txt` allows every crawler and points to `sitemap.xml`; only `send.php` is blocked.
- `sitemap.xml` lists the 11 indexable pages with `lastmod`. `assemble.py` rewrites it on every full run.
- Thin pages carry `noindex, follow`: `saver-login`, `agent-login`, `forgot-password`, `thanks`, `404`.
- Every page has a canonical URL on `https://vochuseasysave.com/`, plus a title naming the brand and what the page offers, a meta description and Open Graph tags (`og:locale` en_NG). Pages are `lang="en-NG"`.
- Structured data (JSON-LD, generated by `assemble.py`):
  - Home: `Organization` (Vochus Easy Save, parent Zipwaves Technologies Limited, address, phone, email, logo) and `WebSite`. Both carry the alternate names "Vochus", "Easy Save" and "Vochus EasySave", so Google ties those searches to the site.
  - FAQ: `FAQPage` built from the questions on the page.
  - Other indexable pages: `BreadcrumbList`.
- Icons Google can show in results: `favicon.ico` (16/32/48), a 192px PNG, and a 512px logo used in the Organization data.
- IndexNow key file at the site root (`<32-hex>.txt`) so Bing, Yandex and others can be told about new or changed pages instantly.

## Off the site (owner, one-off)

1. **Google Search Console** (search.google.com/search-console): add a **Domain** property for `vochuseasysave.com`, then verify it with the TXT record Google gives you (DirectAdmin → DNS Management → Add Record, Type TXT, Name blank/`vochuseasysave.com.`). Then:
   - Sitemaps → submit `https://vochuseasysave.com/sitemap.xml`
   - URL Inspection → `https://vochuseasysave.com/` → Request indexing
2. **Bing Webmaster Tools** (bing.com/webmasters): sign in and choose **Import from Google Search Console**. This also covers DuckDuckGo and Yahoo.
3. **Google Business Profile** (business.google.com): "Vochus Easy Save", category Financial service / Savings, address 286 Ikorodu Road, Lagos, website https://vochuseasysave.com. This is what makes the brand panel and map listing appear for "Vochus".
4. **Links to the site**:
   - from the Vochus app (easysave.vochusglobalservices.co.uk), e.g. its footer or login page
   - from every social profile, the WhatsApp Business profile and the Play listing if the apps go there
   - from Zipwaves' own site

   Each one helps Google trust the domain. If social profiles are created, add their URLs to `sameAs` in `ORG` in `_tools/assemble.py`.

## What to expect

- **"Vochus", "Vochus Easy Save", "vochuseasysave"**: these are distinctive, so once Google has indexed the site (usually days, sometimes 1 to 3 weeks after Search Console submission) it should rank first.
- **"Easy Save" on its own**: a generic phrase other apps and banks also use. The alternate names and links help, but a top position is not guaranteed; it grows with links, reviews and brand searches over time.
- Track progress in Search Console → Performance (queries and positions).

## After each content update

Re-run `python3 _tools/assemble.py` (refreshes the sitemap dates), upload, then ping IndexNow:

```sh
KEY=$(basename [0-9a-f]*.txt .txt)
curl -s "https://api.indexnow.org/indexnow?url=https://vochuseasysave.com/&key=$KEY"
```
